웹앱선생님들이 링크를 눌러 여는 입력 화면(지금 보고 계신 이 화면)입니다. 스프레드시트를 몰라도 이 화면만 쓰면 됩니다.

  • 생김새: https://docs.google.com/spreadsheets/d/(긴 영문·숫자)/copy 처럼 끝이 /copy로 끝납니다.

접속코드선생님들이 웹앱을 처음 열 때 넣는 비밀번호입니다. 링크가 밖으로 퍼져도 학생 이름이 보이지 않게 막아 줍니다. (한 번 넣으면 기억합니다)
관리자코드학생 명단을 올릴 때만 필요한 비밀번호입니다. 관리 선생님만 알고 있으면 됩니다.
준비물 · PC(크롬 브라우저 권장) · 구글 계정(학교 구글 계정이 있으면 그것을 권장) · NEIS에서 내려받은 학적 현황 엑셀 파일

🔗 설치 A · 템플릿 링크를 받은 경우 관리 선생님 1명 · 약 10분

1 구글 계정 확인하기

  • 크롬 오른쪽 위 동그란 프로필 사진을 눌러, 이 프로그램을 관리할 계정으로 로그인되어 있는지 확인합니다.
  • 💡 크롬에 구글 계정이 여러 개 로그인되어 있으면 설치 중 오류가 날 수 있습니다. 가능하면 시크릿 창(Ctrl+Shift+N)을 열어 쓸 계정 하나로만 로그인한 뒤 진행하세요.

2 템플릿 링크로 사본 만들기

  1. 받은 템플릿 링크를 누릅니다(크롬 주소창에 붙여넣고 Enter).
  2. 문서를 복사하시겠습니까? 화면이 나오면 파란색 사본 만들기를 누릅니다.
  3. 잠시 뒤 "…의 사본"이라는 스프레드시트가 열립니다. 왼쪽 위 파일 이름을 눌러 2026 공가대장처럼 알아보기 쉬운 이름으로 바꿔도 됩니다.
이 스프레드시트가 앞으로 모든 기록이 쌓이는 곳입니다. 지우지 마세요. 내 구글 드라이브(drive.google.com)에서 언제든 다시 열 수 있습니다.

3 처음 설정하기 (권한 허용 + 학교 정보 입력)

  1. 스프레드시트 맨 위 메뉴줄(파일 · 수정 · 보기 … 도움말) 오른쪽에 📘 공가대장 메뉴가 생깁니다.
    안 보이면 F5(새로고침)를 누르고 10초쯤 기다리세요.
  2. 📘 공가대장 → ① 처음 설정하기를 누릅니다.
  3. 처음 한 번은 권한을 허락해야 합니다. 다음 순서대로 창이 뜹니다. 당황하지 말고 그대로 누르세요.
    1. 승인 필요 창 → 확인
    2. 계정 선택 창 → 2단계에서 쓴 내 계정 선택
    3. Google에서 확인하지 않은 앱 경고 → 왼쪽 아래 작은 글씨 고급 → 맨 아래 ○○(으)로 이동(안전하지 않음)
    4. 권한 목록 화면 → (체크 칸이 있으면 모두 선택) → 허용 또는 계속
    ❓ "안전하지 않음"이라는데 괜찮나요? 구글에 정식 심사를 받지 않은 개인 프로그램이면 모두 이 문구가 나옵니다. 방금 내가 복사한 프로그램이 내 스프레드시트를 읽고 쓰도록 허락하는 것이고, 다른 사람에게 정보가 가지 않습니다.
  4. 허용이 끝나면 📘 공가대장 → ① 처음 설정하기를 한 번 더 누릅니다. (권한을 허락한 직후에는 창이 안 뜰 수 있어요)
  5. 설정 창에 입력하고 저장을 누릅니다.
    학교명예) OO고등학교 (출력물에 들어갑니다)
    접속코드예) gongga2026 · 선생님들께 알려줄 비밀번호
    관리자코드예) 나만 아는 비밀번호 · 명단 올릴 때 사용 (접속코드와 다르게)
  6. 화면 아래쪽 시트 탭에 학생명단 · 공가기록 · 설정이 보이면 성공입니다.

4 웹앱으로 배포하기 (선생님들이 쓸 링크 만들기)

  1. 📘 공가대장 → ② 웹앱 배포 안내 → 창 안의 Apps Script 편집기 열기 ↗를 누릅니다. 새 탭에 코드가 보이는 화면(편집기)이 열립니다. 코드는 건드리지 마세요.
  2. 편집기 오른쪽 위 파란색 배포 → 새 배포
  3. 유형 선택 글자 옆 ⚙️ 톱니바퀴 → 웹 앱
  4. 세 칸을 이렇게 채웁니다.
    설명공가대장 (아무거나 써도 됩니다)
    다음 사용자 인증 정보로 실행나 (내 이메일) ← 꼭 이것으로
    액세스 권한이 있는 사용자학교 구글 계정(@학교도메인)이면 "○○ 내 모든 사용자"
    개인 구글 계정(@gmail.com)이면 "모든 사용자" (이때는 접속코드를 꼭 정하세요)
  5. 배포를 누릅니다. 액세스 승인이 나오면 3단계와 똑같이 허용합니다.
  6. 새 배포 완료 창에 웹 앱 URL(https://script.google.com/macros/s/…/exec)이 나옵니다. 이 주소를 한 번 눌러 열어 보세요. 지금 보고 계신 것 같은 공가대장 화면이 나오면 성공입니다! (주소가 자동으로 기억됩니다)
  7. 편집기 창에서 완료를 누르고 편집기 탭은 닫아도 됩니다.

5 학생 명단 올리기

  1. NEIS에서 학적 현황 자료를 엑셀로 내려받습니다. 학년별로 파일이 나뉘어도 괜찮고, 열지 말고 그대로 쓰면 됩니다.
  2. 방금 연 웹앱 화면 위쪽 학생 명단 탭 → 파일 선택에서 엑셀 파일을 고릅니다(Ctrl을 누른 채 여러 개 선택 가능).
  3. "읽은 학생 ○○명 (3학년 1반 30명 …)"이 맞는지 확인 → 관리자코드 입력 → 명단 저장
  4. 왼쪽에 학생 목록이 나오면 끝입니다. 학년·반·번호·이름만 저장되고 주소 등은 저장되지 않습니다.

6 선생님들께 링크 보내기

  1. 스프레드시트로 돌아와 📘 공가대장 → ③ 선생님들께 보낼 링크
  2. 안내 문구 복사 → 메신저(쿨메신저 등)에 붙여넣어 담임선생님들께 보냅니다. 링크와 접속코드가 함께 들어 있습니다.
✅ 설치 완료 확인

📄 설치 B · 프로그램 파일로 직접 만드는 경우 템플릿 링크가 없을 때 · 약 15분

프로그램 파일 Code.gs, Index.html 두 개를 받은 경우입니다. 빈 스프레드시트에 코드를 붙여넣은 뒤, 설치 A의 3단계부터 똑같이 하면 됩니다.

1 빈 스프레드시트 만들기

  1. drive.google.com 접속 → 왼쪽 위 + 새로 만들기 → Google 스프레드시트
  2. 왼쪽 위 제목 없는 스프레드시트를 눌러 이름을 2026 공가대장으로 바꿉니다.

2 코드 넣는 곳(편집기) 열기

  1. 스프레드시트 메뉴 확장 프로그램 → Apps Script. 새 탭에 편집기가 열립니다.
  2. 왼쪽 위 제목 없는 프로젝트를 눌러 공가대장 작성프로그램으로 바꿉니다(선택).

3 첫 번째 파일(Code.gs) 붙여넣기

  1. 내 PC의 Code.gs 파일에서 마우스 오른쪽 → 연결 프로그램 → 메모장으로 엽니다.
  2. 메모장에서 Ctrl+A(전체 선택) → Ctrl+C(복사)
  3. 편집기 왼쪽 파일 목록의 Code.gs를 누르고, 오른쪽 코드 칸을 클릭 → Ctrl+A → Delete로 원래 있던 function myFunction() {…}를 지웁니다.
  4. Ctrl+V(붙여넣기)

4 두 번째 파일(Index) 만들어 붙여넣기

  1. 편집기 왼쪽 파일 글자 옆 + → HTML
  2. 이름 칸에 Index라고 쓰고 Enter. (대문자 I, 뒤에 .html은 자동으로 붙음)
  3. 내 PC의 Index.html을 오른쪽 클릭 → 연결 프로그램 → 메모장으로 엽니다. (더블클릭하면 인터넷 창이 열리니 꼭 메모장으로)
  4. 메모장에서 Ctrl+A → Ctrl+C → 편집기의 Index.html 칸에서 Ctrl+A → Delete → Ctrl+V

5 저장하고 확인하기

  1. 위쪽 💾 저장 아이콘(또는 Ctrl+S)을 누릅니다.
  2. 왼쪽 파일 목록에 Code.gs와 Index.html 두 개가 있으면 됩니다.
  3. 스프레드시트 탭으로 돌아가 F5(새로고침) → 메뉴줄에 📘 공가대장이 생기면 성공입니다.
👉 이제 위의 설치 A의 3단계(처음 설정하기)부터 똑같이 진행하세요.

✏️ 공가 입력하기 담임선생님

  1. 받은 링크로 접속합니다. 접속코드를 물으면 관리 선생님께 받은 코드를 넣습니다. (한 번만 넣으면 기억합니다)
  2. 왼쪽 목록에서 3학년 같은 학년 → 1반 같은 반을 누르면 학생이 번호순으로 나옵니다. 위쪽 검색칸에 이름이나 학번을 써도 됩니다.
    학생 옆의 파란 공가 2 표시는 지금까지 입력된 공가 건수입니다.
  3. 학생을 누르면 오른쪽에 입력칸이 나옵니다. 기간 방식을 고르세요.
    • 기간 (시작일~종료일) 하루 이상 빠졌을 때. 하루만이면 시작일=종료일. → 대장에 11.3.(화)~11.5.(목) (3일)
    • 날짜 + 교시 몇 교시만 빠졌을 때 → 대장에 11.10.(화) 1~4교시
  4. 내용(사유)을 쓰고 저장. 입력자(예: 3-1 담임 홍길동)는 한 번 쓰면 기억합니다.
  5. 오른쪽 표에서 기록을 수정 · 삭제할 수 있습니다. 같은 학생에게 날짜가 겹치는 기록이 있으면 저장 전에 알려 줍니다.

🖨️ 대장 출력 · 결재

  1. 위쪽 대장 출력 탭을 누르고, 출력 방식을 고릅니다.
    학년별 · 월별예) 3학년 11월 공가대장. 매달 결재받을 때.
    학년별 누적학년도 전체 / 1학기 / 2학기 / 직접 정한 기간
    학급별한 반의 기록만. 담임이 먼저 확인할 때.
  2. 아래 미리보기가 양식과 맞는지 확인합니다.
  3. 인쇄 / PDF 저장: 인쇄 창에서 A4 · 가로로 나옵니다. 프린터 대신 "PDF로 저장"을 고르면 파일이 됩니다.
    한글(.hwpx) 내려받기: 한글 2014 이상에서 열리며, 글자나 내용을 고칠 수 있습니다.
  4. 쪽마다 14줄과 결재칸(담임·부장·교감)이 있습니다. 출력해서 도장을 받으면 됩니다.
기간이 두 달에 걸친 공가(예: 10.30~11.2)는 두 달의 대장에 모두 나옵니다. 다른 선생님이 방금 입력한 내용이 안 보이면 오른쪽 위 새로고침을 누르세요.

🤝 다른 학교에 나눠주기 (템플릿 링크 만들기)

  1. 내 공가대장 스프레드시트에서 📘 공가대장 → 다른 학교용 템플릿 만들기 → 예
    학생 명단·공가 기록·학교명·코드를 모두 비운 사본이 내 드라이브에 따로 만들어집니다. 지금 쓰는 원본은 그대로입니다.
  2. 창의 템플릿 열기 ↗를 눌러 학생명단·공가기록 시트가 비어 있는지 꼭 확인합니다.
  3. 템플릿 오른쪽 위 공유 → 아래쪽 일반 액세스를 링크가 있는 모든 사용자로 바꾸고, 오른쪽 역할은 뷰어 → 완료
  4. 창에 나왔던 …/copy 주소가 바로 템플릿 링크입니다. 이것을 다른 학교 선생님께 보내 주세요. 받은 분은 설치 A대로 하면 됩니다.
창을 닫아 버렸다면: 템플릿 주소창의 /edit부터 끝까지를 지우고 /copy를 붙이면 같은 링크가 됩니다.

🔄 새 버전으로 바꾸기 고친 프로그램 파일을 받았을 때

  1. 스프레드시트 확장 프로그램 → Apps Script
  2. Code.gs와 Index.html을 각각 전체 선택 → 지우기 → 새 내용 붙여넣기 (설치 B의 3~4단계와 같음) → 💾 저장
  3. 오른쪽 위 배포 → 배포 관리 → 오른쪽 위 ✏️ 연필 → 버전을 새 버전으로 → 배포
이렇게 하면 웹앱 주소와 기록은 그대로 두고 프로그램만 새것으로 바뀝니다. ("새 배포"를 누르면 주소가 바뀌니 주의!)

🆘 막혔을 때

스프레드시트에 [📘 공가대장] 메뉴가 안 보여요.
F5로 새로고침하고 10초쯤 기다리세요. 그래도 없으면 확장 프로그램 → Apps Script에 Code.gs와 Index.html이 있고 저장되었는지 확인하세요.
"이 앱은 차단되었습니다" / "관리자가 차단했습니다"가 떠요.
학교 구글 계정에 외부 프로그램 사용 제한이 걸려 있는 경우입니다. 학교의 구글 계정 관리 담당(정보부)께 문의하거나, 개인 구글 계정으로 설치하세요.
설치 중 "권한이 필요합니다"나 알 수 없는 오류가 나요.
크롬에 구글 계정이 여러 개 로그인되어 있을 때 자주 생깁니다. 시크릿 창(Ctrl+Shift+N)에서 한 계정으로만 로그인해 다시 해 보세요.
담임선생님이 링크를 열면 "액세스 권한 필요"가 떠요.
배포할 때 '액세스 권한이 있는 사용자'가 나만으로 되어 있는 경우입니다. 배포 → 배포 관리 → ✏️에서 "○○ 내 모든 사용자" 또는 "모든 사용자"로 바꾸고 배포하세요. 학교 도메인으로 했다면 선생님도 학교 계정으로 로그인해야 합니다.
웹앱에 "Script function not found: doGet"이 떠요.
Code.gs가 제대로 붙여넣어지지 않았거나 저장 전에 배포한 경우입니다. 코드를 다시 붙여넣고 저장한 뒤 새 버전으로 배포하세요.
메뉴 ③에 "웹앱 주소가 등록되지 않았습니다"라고 나와요.
배포 후 나온 웹앱 주소를 한 번 열어야 기억됩니다. 편집기 배포 → 배포 관리에서 웹 앱 URL을 눌러 연 뒤 다시 메뉴 ③을 누르세요.
"접속코드가 올바르지 않습니다"가 떠요.
관리 선생님께 현재 접속코드를 확인하세요. 코드는 스프레드시트 📘 공가대장 → ① 처음 설정하기에서 바꿀 수 있습니다.
다른 선생님이 입력한 내용이 안 보여요.
오른쪽 위 새로고침을 누르세요. [대장 출력] 탭은 열 때마다 자동으로 최신 내용을 불러옵니다.
새 학년도에는 어떻게 하나요?
새 학년 명단을 다시 올리면 됩니다. 지난 기록은 남아 있고 [대장 출력]에서 학년도를 골라 볼 수 있습니다. 해마다 새로 시작하려면 다른 학교용 템플릿 만들기로 빈 사본을 만들어 쓰세요.
백업은 어떻게 하나요?
스프레드시트 파일 → 다운로드 → Microsoft Excel로 보관하세요. 구글 시트의 파일 → 버전 기록으로 예전 상태를 되돌릴 수도 있습니다.
