야자 감독 온라인 공유 — 구글 시트 설치 안내

담당 선생님이 처음 한 번만 하면 됩니다. 약 10분 걸립니다. 다른 선생님들은 링크만 받으면 됩니다.

학교 구글 계정(Google Workspace)은 외부 공개 설정이 막혀 있는 경우가 많습니다. 아래 7단계에서 [모든 사용자]를 고를 수 없다면 개인 Gmail 계정으로 처음부터 다시 만들어 주세요.

1새 스프레드시트 만들기

구글 드라이브에서 + 새로 만들기 → Google 스프레드시트를 누르고, 이름을 야자 감독 공유처럼 정합니다.
이 시트는 다른 선생님과 공유하지 마세요. 선생님들은 시트가 아니라 웹페이지 링크로 들어옵니다.

2Apps Script 열기

스프레드시트 메뉴에서 확장 프로그램 → Apps Script를 누릅니다. 새 탭에 코드 편집기가 열립니다.

3Code.gs 붙여넣기

왼쪽 파일 목록의 Code.gs(또는 코드.gs)를 누르고, 안에 있는 내용을 모두 지운 뒤 아래 코드를 붙여넣습니다.

4Teacher 파일 만들기

  1. 왼쪽 파일 옆의 + → HTML을 누릅니다.
  2. 이름을 정확히 Teacher 로 입력합니다. (대문자 T, ".html"은 자동으로 붙습니다)
  3. 안에 있는 내용을 모두 지우고 아래 코드를 붙여넣습니다.

위쪽의 💾 저장(Ctrl+S)을 누릅니다.

5초기 설정 · 관리자 키 확인

  1. 스프레드시트 탭으로 돌아가 새로고침(F5)합니다. 잠시 후 메뉴에 야자 감독이 생깁니다.
  2. 야자 감독 → 초기 설정 · 관리자 키 보기를 누릅니다.
  3. 처음에는 권한 승인 창이 뜹니다: 계속 → 내 계정 선택 → "확인되지 않은 앱" 화면이 나오면 고급 → (안전하지 않음)으로 이동 → 허용.
    직접 만든 스크립트라서 나오는 정상적인 안내입니다.
  4. 다시 야자 감독 → 초기 설정 · 관리자 키 보기를 누르면 관리자 키가 보입니다. 복사해 둡니다.
시트 아래에 설정 · 교사 · 배정 · 교체요청 · 변경기록 탭이 생겼으면 성공입니다.

6웹 앱으로 배포

Apps Script 탭에서 오른쪽 위 배포 → 새 배포를 누릅니다.
  1. 유형 선택 옆 ⚙ 톱니 → 웹 앱
  2. 설명: 야자 감독 (아무거나)
  3. 다음 사용자 인증 정보로 실행: 나
  4. 액세스 권한이 있는 사용자: 모든 사용자 ← 꼭 이것으로!
  5. 배포를 누르고, 나오는 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사합니다.
"모든 사용자"여도 이름과 PIN으로 로그인해야 일정을 볼 수 있습니다. 시트 자체는 공개되지 않습니다.

7야자 감독 배정 프로그램과 연결

  1. 야자 감독 배정 프로그램 맨 아래 5. 온라인 공유에 웹 앱 URL과 관리자 키를 붙여넣습니다.
  2. 연결 확인 → "연결됨"이 나오면 감독표 올리기를 누릅니다.

8선생님들께 링크 보내기

웹 앱 URL을 메신저로 보내 주세요. 선생님들은 이름 선택 + PIN(처음 접속 때 직접 정함)으로 들어와서
  • 내 감독 일정 확인, 전체 달력 보기
  • 교체 요청 (날짜 맞바꾸기 / 대신 서 주기) → 상대 선생님이 수락하면 즉시 반영
  • 월~목 · 금 · 토 횟수 확인
을 할 수 있습니다. 휴대폰에서 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다.

✓매달 쓰는 방법

  1. 야자 프로그램에서 온라인 변경 내용 가져오기 — 선생님들끼리 바꾼 내용이 들어오고, 바뀐 날은 🔒 잠금됩니다.
  2. 다음 달로 기간 설정 → 자동 배정 실행 (누적 횟수 반영)
  3. 감독표 올리기
  • PIN을 잊은 선생님: 스프레드시트 메뉴 야자 감독 → 선생님 PIN 초기화
  • 교체 기록: 스프레드시트의 교체요청 · 변경기록 탭에서 언제든 볼 수 있습니다.
  • 코드를 새 버전으로 바꿀 때: 코드를 붙여넣고 저장한 뒤 배포 → 배포 관리 → ✏ 수정 → 버전 새 버전 → 배포. (이렇게 하면 URL이 바뀌지 않습니다)
