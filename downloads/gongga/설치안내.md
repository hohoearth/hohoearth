# 공가대장 작성프로그램 설치 안내 (처음 하시는 분용)

> 같은 내용이 프로그램 화면 위쪽 **[사용 가이드]** 탭에도 있습니다. 설치는 학교에서 **한 분(관리 선생님)만** 하면 되고, 담임선생님들은 링크만 받아 쓰면 됩니다.

---

## 📖 용어 먼저 알기

| 용어 | 뜻 |
|---|---|
| 구글 스프레드시트 | 구글의 인터넷 엑셀. 학생 명단과 공가 기록이 **여기에 저장**됩니다. |
| Apps Script | 스프레드시트 안에 들어 있는 **프로그램 코드**. 배포할 때 한 번 들어가는 것 말고는 손댈 일이 없습니다. |
| 웹앱 | 선생님들이 **링크로 여는 입력 화면**. |
| 배포 | 프로그램을 웹앱 링크로 **공개하는 것**. 배포해야 웹앱 주소가 생깁니다. |
| **템플릿 링크** | 아래 설명 참고 |
| 접속코드 | 선생님들이 웹앱을 처음 열 때 넣는 비밀번호 (학생 정보 보호용) |
| 관리자코드 | 학생 명단을 올릴 때만 쓰는 비밀번호 (관리 선생님만) |

### 템플릿 링크란?
**학생 정보가 하나도 없는 '빈 공가대장 프로그램'을 내 구글 드라이브로 복사해 주는 링크**입니다.

- 링크를 누르면 "문서를 복사하시겠습니까?" 화면이 뜨고, **[사본 만들기]**를 누르면 내 드라이브에 우리 학교 전용 공가대장이 생깁니다. 프로그램 코드도 함께 복사되어 코드를 붙여넣을 필요가 없습니다.
- 복사본은 링크를 준 학교와 **완전히 따로** 움직입니다. 서로의 학생 정보는 보이지 않습니다.
- 생김새: `https://docs.google.com/spreadsheets/d/(긴 영문·숫자)/copy` → **끝이 `/copy`**
- 만드는 사람: 이미 이 프로그램을 쓰고 있는 학교가 메뉴 **[📘 공가대장] → 다른 학교용 템플릿 만들기**로 만듭니다. (맨 아래 "다른 학교에 나눠주기" 참고)

**준비물**: PC(크롬 권장), 구글 계정(학교 계정 권장), NEIS 학적 현황 엑셀

## 🔗 설치 A · 템플릿 링크를 받은 경우 (약 10분)

### 1. 구글 계정 확인
- 크롬 오른쪽 위 프로필 사진을 눌러 **관리할 계정**으로 로그인되어 있는지 확인합니다.
- 💡 계정이 여러 개 로그인되어 있으면 오류가 날 수 있습니다. **시크릿 창(Ctrl+Shift+N)**에서 한 계정으로만 로그인해 진행하면 안전합니다.

### 2. 사본 만들기
1. 템플릿 링크를 크롬 주소창에 붙여넣고 Enter
2. "문서를 복사하시겠습니까?" → **[사본 만들기]**
3. "…의 사본" 스프레드시트가 열림 → 왼쪽 위 이름을 눌러 `2026 공가대장` 등으로 변경(선택)

> 이 스프레드시트가 **모든 기록이 쌓이는 곳**입니다. 지우지 마세요.

### 3. 처음 설정하기
1. 메뉴줄(파일 · 수정 · … · 도움말) 오른쪽에 **[📘 공가대장]**이 생깁니다. 안 보이면 F5 후 10초 기다리기.
2. **[📘 공가대장] → ① 처음 설정하기**
3. 처음 한 번은 권한 허락 창이 차례로 뜹니다.
   1. "승인 필요" → **[확인]**
   2. 계정 선택 → 2단계에서 쓴 **내 계정**
   3. "Google에서 확인하지 않은 앱" → 왼쪽 아래 **[고급]** → 맨 아래 **[○○(으)로 이동(안전하지 않음)]**
   4. 권한 목록 → (체크 칸이 있으면 **모두 선택**) → **[허용]** 또는 **[계속]**

   > "안전하지 않음"은 구글 정식 심사를 받지 않은 개인 프로그램이면 모두 나오는 문구입니다. 내가 복사한 프로그램이 **내 스프레드시트를 쓰도록** 허락하는 것이고, 정보가 다른 곳으로 가지 않습니다.
4. 허락 직후엔 창이 안 뜰 수 있으니 **① 처음 설정하기를 한 번 더** 누릅니다.
5. 학교명 · 접속코드 · 관리자코드(접속코드와 다르게) 입력 → **[저장]**
6. 아래쪽 시트 탭에 `학생명단` · `공가기록` · `설정`이 보이면 성공

### 4. 웹앱으로 배포하기
1. **[📘 공가대장] → ② 웹앱 배포 안내** → **[Apps Script 편집기 열기 ↗]** (코드는 건드리지 않기)
2. 편집기 오른쪽 위 파란 **[배포] → [새 배포]**
3. "유형 선택" 옆 **⚙️ 톱니바퀴 → [웹 앱]**
4. 칸 채우기
   - 설명: `공가대장`
   - 다음 사용자 인증 정보로 실행: **나 (내 이메일)**
   - 액세스 권한이 있는 사용자: 학교 계정이면 **"○○ 내 모든 사용자"**, 개인 gmail이면 **"모든 사용자"**(접속코드 꼭 설정)
5. **[배포]** → "액세스 승인"이 나오면 3단계처럼 허용
6. 나온 **웹 앱 URL**(`…/exec`)을 **한 번 눌러 열기** → 공가대장 화면이 나오면 성공 (주소가 자동으로 기억됨)
7. **[완료]**

### 5. 학생 명단 올리기
1. NEIS에서 **학적 현황** 엑셀 내려받기 (학년별 여러 파일 OK, 열지 말고 그대로)
2. 웹앱 위쪽 **[학생 명단]** 탭 → **[파일 선택]** (Ctrl 누르고 여러 개 선택 가능)
3. 읽은 인원 확인 → **관리자코드** 입력 → **[명단 저장]**

### 6. 선생님들께 링크 보내기
- 스프레드시트 **[📘 공가대장] → ③ 선생님들께 보낼 링크 → [안내 문구 복사]** → 메신저에 붙여넣기 (링크·접속코드 포함)

**✅ 완료 확인**: 시트 3개 있음 / 웹앱 주소가 열림 / 왼쪽에 학생 목록 보임 / 선생님들께 링크 보냄

## 📄 설치 B · 프로그램 파일(Code.gs, Index.html)로 직접 만드는 경우 (약 15분)

1. **drive.google.com → [+ 새로 만들기] → [Google 스프레드시트]** → 이름을 `2026 공가대장`으로
2. 메뉴 **[확장 프로그램] → [Apps Script]** (새 탭에 편집기)
3. **Code.gs 붙여넣기**
   - 내 PC의 `Code.gs` → 마우스 오른쪽 → **연결 프로그램 → 메모장** → Ctrl+A → Ctrl+C
   - 편집기의 `Code.gs` 코드 칸 클릭 → Ctrl+A → Delete → Ctrl+V
4. **Index 파일 만들기**
   - 편집기 왼쪽 "파일" 옆 **[+] → [HTML]** → 이름 `Index` (대문자 I) → Enter
   - 내 PC의 `Index.html` → 오른쪽 클릭 → **연결 프로그램 → 메모장** (더블클릭하면 인터넷 창이 열리니 주의) → Ctrl+A → Ctrl+C
   - 편집기의 `Index.html` 칸에서 Ctrl+A → Delete → Ctrl+V
5. **💾 저장(Ctrl+S)** → 스프레드시트 탭에서 **F5** → **[📘 공가대장]** 메뉴가 생기면 성공
6. 이후는 **설치 A의 3단계(처음 설정하기)**부터 똑같이 진행

## 🤝 다른 학교에 나눠주기 (템플릿 링크 만들기)
1. 내 공가대장 스프레드시트에서 **[📘 공가대장] → 다른 학교용 템플릿 만들기 → [예]** (학생 정보를 비운 사본이 따로 생김, 원본은 그대로)
2. **[템플릿 열기 ↗]** → 학생명단·공가기록 시트가 **비어 있는지 꼭 확인**
3. 템플릿 오른쪽 위 **[공유]** → 일반 액세스를 **"링크가 있는 모든 사용자"**, 역할 **"뷰어"** → **[완료]**
4. 창에 나온 `…/copy` 주소 = **템플릿 링크**. 이것을 다른 학교에 보내면, 받은 분은 설치 A대로 하면 됩니다.
   - 창을 닫았다면: 템플릿 주소에서 `/edit` 부터 끝까지 지우고 `/copy`를 붙이면 됩니다.

## 🔄 새 버전으로 바꾸기
1. **[확장 프로그램] → [Apps Script]** → `Code.gs`, `Index.html` 내용을 새것으로 바꿔 붙여넣기 → 저장
2. **[배포] → [배포 관리] → ✏️ 연필 → 버전: [새 버전] → [배포]**
   - 주소와 기록은 그대로입니다. ("새 배포"를 누르면 주소가 바뀌니 주의)

## 🆘 막혔을 때
- **메뉴가 안 보여요** → F5 후 10초. 그래도 없으면 Apps Script에 두 파일이 저장됐는지 확인
- **"이 앱은 차단되었습니다"** → 학교 계정의 외부 프로그램 제한. 정보부 문의 또는 개인 계정으로 설치
- **알 수 없는 오류/권한 오류** → 여러 계정 동시 로그인 문제. 시크릿 창에서 한 계정으로
- **선생님이 열면 "액세스 권한 필요"** → 배포 관리 ✏️에서 액세스 권한을 "○○ 내 모든 사용자"/"모든 사용자"로 변경
- **"Script function not found: doGet"** → Code.gs 다시 붙여넣고 저장 → 새 버전으로 배포
- **메뉴 ③에 주소가 없다고 나와요** → 배포 관리에서 웹 앱 URL을 한 번 연 뒤 다시 시도
