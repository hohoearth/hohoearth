# 🎓 EduTech Archive - 나만의 교육활동 & 탐구 아카이브

> **doil.dev**에서 영감을 받아 제작된, 과학·정보·융합 교육 교사를 위한 올인원 포트폴리오 및 교육활동 아카이브 웹사이트입니다.  
> 복잡한 프레임워크나 Node.js 설치 없이, **웹 브라우저로 바로 열 수 있으며 GitHub Pages를 통해 무료로 웹에 공개**할 수 있습니다.

---

## 🌟 주요 특징

1. **doil.dev 스타일의 모던 UI & 다크 모드**:
   - 깔끔한 테크/아카이브 카드 그리드 레이아웃
   - 우측 상단 해/달 아이콘을 통한 실시간 다크/라이트 모드 지원 (방문자 브라우저 설정 기억)
2. **5대 핵심 교육 카테고리 지원**:
   - 📖 **수업 아카이브**: 차시별 지도안, 활동지, 슬라이드 링크
   - 🔬 **프로젝트 & 연구**: 과학전람회, 발명품, 학생 탐구 지도 결과물
   - 🛠️ **수업 웹 도구**: 교실에서 바로 쓸 수 있는 인터랙티브 유틸리티
   - 🎤 **연수 & 강연**: 교원 직무연수 교재 및 발표 슬라이드
   - ✍️ **교육 에세이**: 수업 일지, 교육 철학 및 평가 회고
3. **교실에서 바로 쓰는 내장 웹 도구 포함**:
   - 🎲 **발표자 & 모둠 랜덤 추첨기** (번호 범위 지정, 중복 방지, 룰렛 효과)
   - ⏱️ **시각적 모둠 집중 타이머** (원클릭 1·3·5·10분 프리셋, 알림음 지원)
4. **실시간 검색 및 태그 필터링**:
   - 검색창에 키워드 입력 시 제목, 요약, 태그에서 즉시 필터링
   - 카드 속 `#태그`를 클릭하면 해당 주제의 활동들만 모아서 조회 가능
5. **마크다운(Markdown) 상세 뷰어 탑재**:
   - 각 활동 카드를 클릭하면 본문 마크다운 글과 관련 첨부 파일 링크가 세련된 모달로 표시됩니다.

## 🚀 빠른 시작 (실행 방법)

### 1. 로컬에서 바로 열기
- 이 폴더 안에 있는 `index.html` 파일을 마우스로 **더블 클릭**하면 Chrome, Edge 등 브라우저에서 즉시 열립니다!
- 또는 터미널(PowerShell)에서 아래 명령어를 실행해도 됩니다:
  ```powershell
  python -m http.server 8000
  ```
  그 후 브라우저에서 `http://localhost:8000` 접속

## ✏️ 내 정보 및 교육자료 수정하기

코딩을 깊게 몰라도 텍스트 에디터(메모장, VS Code 등)로 파일만 열어서 쉽게 수정할 수 있습니다.

### 1. 프로필 및 사이트 기본 정보 변경
- 파일 위치: `data/site-config.js`
- 선생님 성함(`name`), 역할(`role`), 한 줄 소개(`bio`), 이메일, GitHub 주소 등을 원하는 내용으로 변경하세요.

### 2. 새로운 수업 자료나 활동 추가하기
- 파일 위치: `data/items.js`
- `archiveItems` 배열 안에 새로운 항목 객체를 복사해서 추가하면 웹사이트에 자동으로 등록됩니다:
```javascript
{
  id: "my-new-class",
  category: "class", // 'class', 'project', 'tools', 'lecture', 'essay' 중 선택
  title: "내가 진행한 멋진 수업 제목",
  date: "2026.05",
  year: "2026",
  summary: "카드 목록에 보일 1-2줄 핵심 요약",
  tags: ["과학", "인공지능", "실험"],
  thumbnail: "https://images.unsplash.com/...", // 이미지 주소 또는 로컬 이미지
  featured: true, // 메인에 '추천' 뱃지 표시 여부 (true/false)
  links: [
    { label: "지도안 다운로드", url: "https://...", icon: "file-text" }
  ],
  content: `
### 수업 개요
여기에 마크다운 문법으로 자세한 내용을 자유롭게 작성할 수 있습니다!
- 차시별 활동 내용
- 학생들의 소감
  `
}
```

## 🌐 무료로 웹에 배포하기 (GitHub Pages)

인터넷 주소(예: `username.github.io/my-archive` 또는 나만의 도메인)로 모든 사람이 볼 수 있게 하는 가장 쉬운 방법입니다.

1. **GitHub**([github.com](https://github.com))에 회원가입 후 새 저장소(New Repository)를 생성합니다.
2. 이 폴더의 모든 파일(`index.html`, `css/`, `js/`, `data/`)을 해당 저장소에 업로드합니다.
3. GitHub 저장소의 **[Settings]** 탭 -> 좌측 **[Pages]** 메뉴로 이동합니다.
4. **Branch**를 `main` (또는 `master`)으로 선택하고 **Save**를 누릅니다.
5. 1~2분 뒤 나만의 웹사이트 주소가 생성되어 전 세계 어디서든 접속할 수 있습니다! 🎉
